# 달리기 자세 분석 AI 모델 (오픈소스 기반) 제안서

## ⚡ LLM 기반 개발 도입 기념 — 한정 할인가

> **정상가 2,000만원 → 특가 1,500만원 (25% 할인)**
> 동일 범위 일반 외주 단가 대비 **약 25% 절감**된 금액으로 제공됩니다.

LLM으로 반복적인 보일러플레이트·문서·테스트 코드 작업을 자동화하고, 개발자는 도메인 설계와 모델 검수에 집중합니다. 결과: **더 빠른 납기, 더 정확한 산출물, 더 낮은 단가**.

---

## 1. 프로젝트 이해

스마트폰 영상으로 촬영한 달리기 영상을 분석하여 **부상 위험도 + 교정 처방**을 자동 산출하는 AI 모델 + API 서버를 구축하는 프로젝트입니다.

핵심 차별 포인트는 **자체 모델 학습 대신 오픈소스 + 상용 API 조합**으로 비용·기간을 단축하는 것이며, 정형외과 원장님이 음성으로 편리하게 소견을 입력할 수 있는 **STT 기반 라벨링 툴**이 데이터 품질의 핵심입니다.

핵심 요구사항을 다음과 같이 정리했습니다:

- **음성 라벨링 툴** — Whisper STT + GPT-4o-mini 정형화로 의사 소견을 위험도/이상부위/처방으로 자동 분리
- **MediaPipe 자세 분석** — 33-keypoint 추출 + 노이즈 필터 + 생체역학 지표 계산
- **부상 위험도 + 처방 추론** — 룰 기반 또는 경량 모델로 위험도 수치화 + 처방 매칭
- **REST API 서빙** — FastAPI + Token 인증, 모바일 앱이 그대로 호출 가능

## 3. 기술 스택 — 브리프 권장 스택 채택

| 영역 | 기술 | 선정 이유 |
|---|---|---|
| 자세 추출 | **MediaPipe Pose** | 단일 이미지 33-keypoint, 모바일 친화 경량 모델 |
| 보강 (선택) | YOLOv8 Pose | 정확도 더 필요 시 fallback |
| STT | **Whisper API** | 한국어 인식 정확도 최상, 의학 용어 어휘 적응 가능 |
| LLM 정형화 | **GPT-4o-mini** | 함수 호출(JSON Schema)로 항목 자동 분리, 비용 효율 |
| 백엔드 | **FastAPI** + Pydantic | 자동 OpenAPI 문서, 비동기 처리, Python 생태계 |
| 라벨링 툴 | **Streamlit** | 의사 사용자 대상 빠른 구축, Python 단일 코드베이스 |
| DB | PostgreSQL | 라벨 + 분석 결과 + 환자 메타 통합 저장 |
| 배포 | Docker + 클라우드 (협의) | AWS/NCP/GCP 모두 호환 |
| 인증 | Bearer Token (JWT) | 모바일 앱이 그대로 호출 가능 |

## 4. 작업 범위 — 브리프 [2-1 ~ 2-4] 구현

### 4-1. 음성 기반 라벨링 툴 (브리프 2-1)
- 영상 업로드 + 프레임 분석 뷰어 (전·후·측면)
- 마이크 녹음 + Whisper STT
- GPT-4o-mini로 의학 용어 오타 교정
- **위험도 / 이상 부위 / 교정 처방 항목 자동 정형화** (JSON Schema 함수 호출)
- 수동 수정 UI 제공
- DB 저장 + 라벨 이력 조회

### 4-2. 오픈소스 자세 분석 모델 (브리프 2-2)
- MediaPipe로 영상 프레임별 33-keypoint 추출
- 시간 축 노이즈 필터 (Savitzky-Golay 또는 Kalman)
- **생체역학 지표 계산**:
  - 케이던스 (분당 걸음 수)
  - 보폭 (m)
  - 지면 접촉 시간 (ms)
  - 무릎/발목/엉덩이 굽힘 각도
  - 체간 전방 기울기
  - 수직 진폭

### 4-3. 부상 위험도 + 처방 추론 (브리프 2-3)
- 추출 지표 + 의사 라벨 매핑 룰셋 작성
- 가중치 기반 위험도 수치 산출 (0~100)
- 위험도 + 이상 부위 → 처방 텍스트 매칭
- 신뢰도 점수 + 근거(왜 이 위험도인지) 함께 반환

### 4-4. 모델 서빙 + API (브리프 2-4)
- FastAPI 서버 + 자동 OpenAPI 문서
- POST /v1/analyze (영상 업로드 → JSON 결과)
- GET /v1/analyses/{id} (이력 조회)
- POST /v1/labels (의사 라벨 저장)
- Bearer Token 인증 미들웨어
- 업로드 영상 24시간 후 자동 삭제 (개인정보 보호)
- Docker Compose로 단일 명령 배포

### 비기능
- 60초 영상 기준 평균 응답 3~5초
- HTTPS 강제, 모든 요청 로그
- 환경변수로 API 키 분리

## 8. 리스크 관리 — 사전 합의 권장 사항

### 8-1. MediaPipe 정확도 한계 (단안 카메라)
3D 좌표 추정은 단일 카메라에서 ±2~5° 오차가 발생할 수 있으며, 빠른 동작 시 motion blur로 일부 키포인트가 누락됩니다.

→ **1주차 PoC에서 정확도 한계를 의사 원장님께 시연**하고, 허용 오차 범위(예: 관절 각도 ±5° 이내)를 명문화한 뒤 추론 로직을 설계합니다.

### 8-2. 데이터 라벨링 시간 확보
의사 라벨이 충분히 누적되지 않으면 룰 기반 추론의 신뢰도가 떨어집니다.

→ 발주처 측에서 **주 5시간 이상의 라벨링 시간 확보**를 약속해 주시면, 8주차 완료 시점에 30개 이상의 케이스 기반으로 룰셋을 검증할 수 있습니다.

### 8-3. 의료 책임 면책
본 결과물은 **운동 자세 분석 및 부상 예방 참고용**이며, 의학적 진단·처방을 대체하지 않습니다.

- 임상시험·식약처 의료기기 인허가 절차는 본 계약 범위 외
- 환자 사용 시 발생하는 의료적 책임은 발주처가 부담

→ **계약서에 위 면책 조항 명시 부탁드립니다.**
